# 内容修订不可变，发布窗口与当前权限分离

使用稳定 Document 身份、不可变 DocumentRevision 和独立 Publication 生效窗口，替代更新时覆盖原文或删除旧 Chunk 的方案，以支持历史业务时点检索、可追溯引用和失败回滚。构建在后台完成，只有完整 revision 才能事务性发布；同一 Document 的生效窗口不重叠。

代价是保留历史内容、构建状态和发布审计，增加存储与管理操作。当前 ACL、撤回和删除对所有历史查询持续生效，索引和内容回滚不得恢复旧权限；首版不支持“当时系统已知什么”的双时间重放。详细规则见 [接口契约](../contracts.md)。
